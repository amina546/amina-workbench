# Amina Workbench

个人生产力工作台 — 每日计划、账单、资产、复盘、健康、影评、日历，支持多端同步。

## Deploy to Render

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/amina546/amina-workbench)

## Tech Stack

- Frontend: HTML / CSS / JavaScript (vanilla)
- Backend: Node.js + Express
- Storage: JSON file DB
- Sync: REST API with token auth

## Local Development

```bash
npm install
node server.js
```

Open http://localhost:3000
